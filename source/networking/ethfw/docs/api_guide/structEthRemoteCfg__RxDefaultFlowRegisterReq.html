EthRemoteCfg_RxDefaultFlowRegisterReq Struct Reference

Detailed Description

Request params for ETHREMOTECFG_CMD_SET_RX_DEFAULTFLOW or ETHREMOTECFG_CMD_DEL_RX_DEFAULTFLOW commands.

This structure holds info about the rxFlowIdx which needs to be registered or de-registred as default flow.
