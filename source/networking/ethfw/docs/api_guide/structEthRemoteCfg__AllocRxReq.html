EthRemoteCfg_AllocRxReq Struct Reference

Detailed Description

Request params for ETHREMOTECFG_CMD_ALLOC_RX command.

This request provides the rx flow to the client which needs to be allocated. FlowIdx 0U being given to default flow and any custom policers cannot be created for it.
