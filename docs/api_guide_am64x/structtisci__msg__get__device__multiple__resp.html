Detailed Description

Response containing device states as bitmap.

Returns a bitmap where each device uses 2 bits to represent its state: 00 = OFF, 01 = ON, 10 = TRANSITIONING, 11 = reserved for future use. The device state will be present at the index corresponding to the device ID. If a device ID does not exist at a particular index, the value at that index will be 0 (OFF).

Parameters
hdrTISCI header
countNumber of device states included in this response.
remainingNumber of remaining devices that did not fit in this response.
device_state_bitmapBitmap indexed by device ID. Each device uses 2 bits.
