Typedef Documentation

◆ Crypto_ShaCallback

typedef uint32_t(* Crypto_ShaCallback) (uint8_t *inputBuf, uint32_t inputLenBytes, uint8_t *digestBuf)

Callback used by Crypto_MGF1/Crypto_PSSPaddingForSign/Crypto_PSSVerify to compute a hash digest. Same parameter shape as AsymCrypt_ExecuteShaCallback (asym_crypt.h) so existing SHA wrapper functions can be passed in directly without an adapter.

Note
Crypto_MGF1/Crypto_PSSPaddingForSign/Crypto_PSSVerify share internal static scratch buffers (to keep their stack footprint small) and are therefore NOT reentrant: do not call them concurrently from multiple contexts (e.g. an ISR and main, or multiple RTOS tasks) or recursively/nested within each other.
Parameters
inputBufBuffer to hash
inputLenBytesLength of inputBuf in bytes
digestBufResultant digest buffer (caller-sized to hashLenInBytes)
Returns
0 on success, non-zero on failure

void Crypto_PKCSPaddingForSign ( const uint8_t *  shaHash,
uint32_t  keyLengthInBytes,
uint32_t  typeOfAlgo,
uint8_t *  output 
)

Padding function for sign.

Builds the full EMSA-PKCS1-v1_5 encoding as per RFC 8017 Section 9.2: EM = 0x00 || 0x01 || PS (0xFF..) || 0x00 || DigestInfo (ASN.1 DER) || Hash

Parameters
shaHashCalculated Hash of the message for padding
keyLengthInBytesUsed while padding to match key and padded mesage size. Must be >= 3 + digestInfoLen + hash length for typeOfAlgo, otherwise output is left untouched.
typeOfAlgoUsed while padding to check sha length, refer Crypto_AlgoTypes
outputResultant padded buffer stored in dest

◆ Crypto_PSSPaddingForSign()

uint32_t Crypto_PSSPaddingForSign ( Crypto_ShaCallback  shaCbFxn,
uint32_t  typeOfAlgo,
const struct Crypto_PSSSaltInfo *  saltInfo,
uint32_t  modBits,
uint32_t  emLenInBytes,
uint8_t *  output 
)

Builds the EMSA-PSS encoding for RSA signing, refer to RFC 8017 Section 9.1.1 https://www.rfc-editor.org/rfc/rfc8017#section-9.1.1.

EM = maskedDB || H || 0xBC, where M' = 0x00^8 || mHash || salt, H = Hash(M'), DB = 0x00^psLen || 0x01 || salt, maskedDB = DB XOR MGF1(H, dbLen), with the leftmost bits of maskedDB[0] cleared per emBits = modBits - 1.

Parameters
shaCbFxnHash callback, refer Crypto_ShaCallback
typeOfAlgoHash algorithm used for mHash/H/MGF1, refer Crypto_AlgoTypes
saltInfoMessage hash and salt, refer Crypto_PSSSaltInfo
modBitsBit length of the RSA modulus n
emLenInBytesLength of the output EM buffer (ceil(modBits/8))
outputResultant EM buffer, emLenInBytes long
Returns
0 on success, non-zero on failure (shaCbFxn failure or emLenInBytes too small)

Verifies an EMSA-PSS encoding for RSA signature verification, refer to RFC 8017 Section 9.1.2 https://www.rfc-editor.org/rfc/rfc8017#section-9.1.2.

Recovers the salt from EM itself (unlike re-running Crypto_PSSPaddingForSign, which requires the original salt and is therefore NOT valid verification).

Parameters
shaCbFxnHash callback, refer Crypto_ShaCallback
typeOfAlgoHash algorithm used for mHash/H/MGF1, refer Crypto_AlgoTypes
msgHashmHash, precomputed hash of the message, hashLenInBytes long
saltLenInBytesExpected salt length
modBitsBit length of the RSA modulus n
EMEncoded message recovered from the signature (RSA public op output)
emLenInBytesLength of EM in bytes
Returns
0 if consistent (verification passed), non-zero if inconsistent or on failure
