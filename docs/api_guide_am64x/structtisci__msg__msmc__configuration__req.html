TISCI Data structures and macros for MSMC gasket configuration

Request for TISCI_MSG_CONFIGURE_MSMC_GASKET.

This message allows configuration of MSMC gasket registers to set/get the timeout value, enable timeout detection counter and force timeout interrupt generation for a CPU in ASIL-B domain.

Parameters
hdrTISCI header containing message information.
reg_addrPhysical address of the MSMC gasket register to configure.
reg_valValue to write to the specified MSMC gasket register.
req_typeType of configuration request: 0xAA - Read register operation 0xBB - Write register operation
