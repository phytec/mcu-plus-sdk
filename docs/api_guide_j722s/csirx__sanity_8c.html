uint32_t CSIRX_ConfigSF ( const CSIRX_Config *  obj)

This file contains sanity API functions. The purpose of sanity functions is to check input parameters validity. They take the same parameters as original API functions and return 0 on success or CDN_EINVAL on wrong parameter value(s). Function to validate struct Config

Returns
