Introduction

This Ethernet Firmware example demonstrates ability to perform traffic steering from CPSW to multiple cores. This uses hardware capabilities of CPSW to direct unicast traffic, and a shared memory based layer to send multicast and broadcast traffic.

Ethernet Firmware server is the application which owns the CPSW peripheral, and controls the behaviour. Ethernet firmware clients are the applications which are running on different cores, which send requests to ethernet firmware server based on their requirements.

This example demonstrates multi-core ethernet support on J722S using CPSW. The server runs on MAIN-R5F core and manages CPSW peripheral, while client applications on MCU-R5F core communicate via shared memory IPC.

Steps to Run the Example

Prerequisites

  • J722S EVM Board
  • CAT6 Ethernet cable

Build the example

  • When using CCS projects to build, import the CCS project for the required combination and build it using the CCS project menu (see Using SDK with CCS Projects).
  • When using makefiles to build, note the required combination and build using make command (see Using SDK with Makefiles)

HW Setup

  • Connect one end of the CAT6 cable to the EVM and the other end to the network.

Run the example

Attention
If you need to reload and run again, a CPU power-cycle is MUST.
  • Load main-r5 Server binary in CCS in main-r5f core after doing a power/system reset.
  • Load the other binaries via CCS on mcu-r5f core as per need
  • You will see logs in the UART terminal as shown in the next section.
  • The prints will indicate the IP address acquired by clients against their corresponding MAC addresses

MAC Port Configuration

Default Out-of-Box Configuration

The Ethernet firmware on J722S is configured with the following default port settings:

  • MAC Port 1: Enabled in RGMII mode with integrated PHY support
  • MAC Port 2: Disabled (NO-PHY mode) by default

MAC Port 2 can be configured by the user to operate in SGMII mode for SerDes-based connectivity. However, since integrated PHY support for SGMII is not available on J722S, MAC-to-MAC mode must be employed. This mode enables direct connection between J722S and another Jacinto device (such as J721E or similar) through an Ethernet Expander Bridge, allowing SGMII functionality via the remote device's SGMII port.

Enabling SGMII Mode on MAC Port 2

To configure SGMII operation on MAC Port 2 of the J722S Ethernet firmware, perform the following steps:

  1. Enable SGMII in board configuration - Modify <SDK_INSTALL_PATH>/source/networking/ethfw/utils/board/src/j722s/board_j722s_evm.c:
    • Set #define ENABLE_SGMII to 1
  2. Enable SGMII in SoC configuration - Modify <SDK_INSTALL_PATH>/source/networking/enet/soc/k3/j722s/enet_soc_cfg.h:
    • Set #define ENET_CFG_CPSW_SGMII to (ENET_ON)
    • Set #define ENET_CFG_CPSW_MACPORT_SGMII to (ENET_ON)
  3. Configure CPSW pinmux in SysConfig - Update example.syscfg using the SysConfig GUI:
    • Navigate to CPSW pinmux config
    • Set MAC Port 2 Interface Mode to SGMII from the dropdown menu
  4. Establish board-to-board connection - Connect the J722S board to a compatible Jacinto board (J721E or equivalent) using an Ethernet Expander Bridge:
    • Connect the SGMII port of the remote Jacinto device to serve as the SGMII interface for J722S MAC Port 2
  5. Rebuild firmware and applications - Rebuild the libraries first, then the apps before loading the binaries
