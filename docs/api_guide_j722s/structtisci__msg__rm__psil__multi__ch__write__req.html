tisci_msg_rm_psil_multi_ch_write_req Struct Reference
APIs for SOC Specific Device Drivers » APIs for SCI Client or SYSFW » Texas Instruments System Controller Interface » tisci_rm_psil

Detailed Description

Writes the same PSI-L thread configuration register to multiple threads via the PSI-L configuration proxy. Thread i is addressed as: thread + (i * stride).

Parameters
hdrStandard TISCI header
valid_paramsReserved for future use; initialize to zero
nav_idSoC device ID of Navigator Subsystem
threadFirst PSI-L thread ID
num_threadsNumber of threads to write (>= 1)
strideThread ID increment per step (1 = consecutive)
taddrRegister address (same for all threads)
dataBits to set/clear within mask
maskBitmask selecting which bits to modify
rsvdReserved; set to zero
